# Supplied FreshPick UI kit

Imported from the user-provided `freshpick_ui_kit` folder on 2026-10-26.

- `brand/`: apple logo mark, horizontal wordmark and app icon.
- `illustrations/`: hero, placeholder artwork, shutter and status artwork.
- `icons/`: individual 24px SVGs used as CSS masks with the current text color.
- `design-tokens.css` and `design-tokens.json`: original supplied token values.

The prototype HTML, component screenshots and assembled component SVGs were used
as visual references. Actual controls remain semantic HTML buttons, tabs, inputs
and live video connected to the existing inference service. The apple artwork is
decorative branding; supported model labels remain the existing eight produce.

The kit specifies Inter / Plus Jakarta Sans with a system fallback. It contains
no font files. The app uses that stack and makes no external font request.
